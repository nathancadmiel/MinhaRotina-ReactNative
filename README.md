# MinhaRotina

Aplicativo mobile desenvolvido para auxiliar na organização da rotina diária, permitindo o gerenciamento de tarefas de forma simples e prática.

## Funcionalidades

- Cadastro e login de usuários
- Gerenciamento de tarefas
- Edição e exclusão de tarefas
- Marcação de tarefas como concluídas
- Armazenamento de dados utilizando Firebase e MySQL

## Tecnologias Utilizadas

### Frontend
- React Native
- Expo
- React Navigation

### Backend
- Node.js
- Express

### Banco de Dados
- Firebase Authentication
- Firebase Firestore
- MySQL

## Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/MinhaRotina.git
```

2. Acesse a pasta do projeto:

```bash
cd MinhaRotina
```

3. Instale as dependências do projeto:

```bash
npm install
```

4. Instale as dependências do backend:

```bash
cd backend
npm install
```

5. Inicie o servidor:

```bash
npm start
```

Caso o comando acima não funcione:

```bash
node server.js
```

6. Em outro terminal, volte para a pasta principal e execute o aplicativo:

```bash
npx expo start
```

Depois, escaneie o QR Code utilizando o aplicativo Expo Go.
